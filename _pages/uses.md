This page lists some of the tools and things I use regularly. It's inspired by the many people who've shared their own setups over o [uses.tech](https://uses.tech/).


## Hardware

- MacBook Air - My main computer for development & writing.
- Jarvis Standing Desk - Had it for a while and still standing strong. Sometimes use it in the standing setting.

## Software

- [Obsidian](https://obsidian.md/) - For note taking, to-do lists, second brain. Effectively a catch all for all types of notes.
- Visual Studio Code - Current IDE, just jumped on the bandwagon after using Sublime Text for so long.
- [Firefox](https://firefox.com) - Current browser of choice.
- LastPass - My current password manager with plans to move to Bitwarden.
- [iTerm2](https://iterm2.com/) - Terminal emulator.
- [Oh My Zsh](https://ohmyz.sh/) - The shell and configuration framework I use.
- [dotfiles](https://github.com/jjgrainger/dotfiles) - My own dotfiles to configure my laptop and development environment.
- [Docker](https://www.docker.com/) - Used to create local environments for many projects I work on.


## Analogue

- [Moleskine](https://www.moleskine.com) notebooks - Notes, sketches and freeform ideas. Usually go for the Cahier Journals, both large and pocket sized.
